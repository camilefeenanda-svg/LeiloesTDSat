# 🏷️ Sistema de Leilões

## 📌 Descrição

Este projeto consiste em um sistema desktop desenvolvido em Java para gerenciamento de produtos em uma casa de leilões.

O sistema permite o cadastro, listagem e venda de produtos, além do controle de status dos itens (disponível ou vendido).

---

## ⚙️ Funcionalidades

* ✅ Cadastro de produtos
* ✅ Listagem de produtos cadastrados
* ✅ Venda de produtos
* ✅ Atualização automática do status para "Vendido"
* ✅ Listagem de produtos vendidos
* ✅ Integração com banco de dados MySQL

---

## 🛠️ Tecnologias Utilizadas

* Java
* MySQL
* Git
* GitHub

---

## 💾 Banco de Dados

O sistema utiliza um banco de dados MySQL para armazenar as informações dos produtos.

Estrutura básica:

* ID
* Nome
* Valor
* Status (Disponível / Vendido)

---

## ▶️ Como Executar o Projeto

1. Clone o repositório:

```
git clone https://github.com/camilefeenanda-svg/LeiloesTDSat.git
```

2. Abra o projeto no NetBeans ou IDE de sua preferência

3. Configure a conexão com o banco de dados no arquivo de conexão

4. Execute o projeto
